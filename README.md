One image that sums up Wednesday 18 November 2026: the historic first US-China-Russia
leaders' summit at APEC Shenzhen (Putin lands, Trump arrives), Voyager 1 reaching one
light-day from Earth, Gulf tensions after a tanker mined near Hormuz, Saudi-led strikes
on Yemen, UK sanctions on settlement firms, Mongolia's president resigning, a Czech
train collision, US AI-chip export curbs, WHO's obesity call - drawn with PIL, one
composition, legible at 300 px.

The program copies `entry.png` to `/output/entry.png` (Node 22, standard library only).
The drawing script itself lives outside the entry: the shipped image is the work.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
